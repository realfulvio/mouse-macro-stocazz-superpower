# Cavallini e font

Progetto e design: hcok.

Windows v0.17 usa i quattro PNG consegnati nel handoff grafico approvato: Pronto, Registrazione, Riproduzione ed Errore. I file originali sono in `assets/horses`; il rendering seleziona la regione illustrata senza mostrare le scritte di catalogo. Il font è Outfit, incluso con licenza OFL, e le icone SVG del handoff vengono disegnate alla scala DPI corrente.

La UI Linux storica conserva i precedenti asset `pony-record.png` e `pony-director.png` e il font emoji locale. Gli asset approvati Windows restano distinti.
